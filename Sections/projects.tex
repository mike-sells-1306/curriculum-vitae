\subsection{Comparative Study of Language Effects on RISC-V RV32I Emulation Performance}
\begin{subs}
    \noindent\textbf{Undergraduate dissertation} (ongoing) \par
    \noindent Design and implementation of two RISC-V RV32I system emulators, one in Rust and one in C, to empirically compare performance and safety trade-offs between the languages.
    \begin{itemize}
        \item Implemented a RISC-V RV32I processor core and memory-mapped I/O environment in both Rust and C from the ISA specification, enabling a direct comparison between implementations
        \item Structured the study around three research questions: performance parity, engineering trade-offs, and isolating safety-overhead cost.
        \item Built the project with production-style software practices: modular crate structure, optional CLI functionality gated behind a feature flag, and a maintained documentation wiki
    \end{itemize}
\end{subs}

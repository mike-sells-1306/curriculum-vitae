\subsection{Comparative Study of Language Effects on RISC-V RV32I Emulation Performance}
\begin{subs}
    \noindent\textbf{Undergraduate dissertation} (ongoing: expected June 2027) \par
    \noindent Design and implementation of two RISC-V RV32I system emulators, one in Rust and one in C, to empirically compare performance and safety trade-offs between the languages.
    \begin{itemize}
        \item Implemented a RISC-V RV32I processor core and memory-mapped I/O environment in both Rust and C on Ubuntu, from the ISA specification, enabling a direct comparison between implementations
        \item Structured the study around three research questions: performance parity, engineering trade-offs, and isolating safety-overhead cost.
        \item Built the project with production-style software practices: modular structure (Cargo crates in Rust, static libraries in C), optional CLI functionality gated behind a feature flag, and a maintained documentation wiki
    \end{itemize}
\end{subs}
